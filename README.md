# Customer Shopping Behavior Analysis

Retail analytics project analyzing **3,900 customer transactions** using **Python, MySQL, and Power BI** to uncover customer trends, spending behavior, discount dependency, and product performance.

## Key Highlights
- Cleaned and analyzed retail transaction data with 18 features
- Built 10 MySQL business queries for customer insights
- Created interactive Power BI dashboard
- Performed customer segmentation and product analysis

## Tech Stack
- Python (pandas)
- MySQL
- Power BI

## Main Insights
- Loyal customers formed the majority of shoppers
- Young Adults generated the highest revenue
- Some products showed high discount dependency
- Subscriber and non-subscriber spending was nearly identical

## How to Run

### Install Dependencies
```bash
pip install pandas sqlalchemy pymysql
```

### Run Preprocessing
```bash
python preprocess.py
```

### Run SQL Queries
Execute the queries inside your MySQL database.

### Open Dashboard
Open `customer_behavior_dashboard.pbix` in Power BI Desktop.
